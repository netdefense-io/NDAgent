# Security Policy

## Supported Versions

Security fixes are made against the latest released version of NDAgent. We
recommend always running the most recent release available from the
NetDefense package repository. Older versions are not maintained.

## Reporting a Vulnerability

Please report security vulnerabilities using [GitHub private vulnerability
reporting](https://github.com/netdefense-io/NDAgent/security/advisories) on
this repository. This opens a private channel with the maintainers and keeps
the report out of public view until a fix is available.

**Please do not open public GitHub issues for security vulnerabilities.**

We aim to send an initial response within **5 business days** of a report.

## Scope

This repository mirrors the source of the NDAgent device daemon and its
OPNsense plugin. Reports about the agent itself, as well as reports about the
hosted NetDefense platform (the server-side components the agent connects
to), are both welcome through the same channel above.
